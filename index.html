Konfigurasi Google Sheets / Apps Script

Aplikasi ini dapat membaca database kelulusan menggunakan dua metode: **Google Apps Script Web App URL (Sangat Direkomendasikan - Real-time)** atau **Google Sheets CSV Publik**.

Cara Menggunakan Google Apps Script (Real-time):

  1. Buka spreadsheet data kelulusan Anda di Google Drive.
  2. Pilih menu **Ekstensi** > **Apps Script**.
  3. Salin kode Google Apps Script (`code.gs`) yang disediakan sekolah ke dalam editor tersebut.
  4. Klik **Terapkan (Deploy)** > **Terapkan Baru (New Deployment)**.
  5. Atur jenis penerapan ke **Aplikasi Web (Web App)**.
  6. Atur akses *"Yang memiliki akses"* ke **Siapa saja (Anyone)** dan klik **Terapkan**.
  7. Salin **URL Aplikasi Web** yang diberikan lalu tempelkan di bawah ini.
